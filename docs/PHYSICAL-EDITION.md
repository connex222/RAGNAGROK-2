# Physical / Hybrid Adaptation — Feasibility Concept

This is an exploration document, **not** a manufacturing specification or completed prototype.

## Standalone physical version

A smaller 3–5-player game on modular garden hexes is the more practical tabletop format. Draft god cards, secretly choose action cards, resolve actions in printed order, reveal forecast disaster cards, then run simple award categories. Use resource cubes, ownership markers, feature tiles, health pips and a single shared scoring track. Reduce status-condition tokens and simplify targeted effects. Avoid reproducing the 24-round Epic mode in cardboard without playtesting its handling time.

The risks are component cost, fiddly bookkeeping, board crowding and slow disasters. The strongest candidate is a 45–60-minute compact game rather than a direct 1:1 software port.

## Hybrid physical / app version

Use the tabletop pieces for land and feature placement, with private phones for action selection and the shared screen/companion app for forecasts, resolution and scoring. This preserves tactical layout while eliminating most manual calculations and protecting secret orders. The risks are device dependence, connectivity and a less self-contained retail product.

## Recommendation

Prototype the **hybrid** experience first with paper hexes and the existing V2 engine. Separately run a minimal 3–5-player fully physical prototype with fewer conditions and shorter matches. Compare session setup, average resolution time, player enjoyment and component requirements before commissioning art or paying for samples.
